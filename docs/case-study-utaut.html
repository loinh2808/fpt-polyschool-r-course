Case Study 1: UTAUT and PLS-SEM

Students’ Acceptance of ChatGPT in Higher Education

Overview

NoteCase Purpose

This case study teaches learners how to move from a published technology-acceptance paper to a reproducible PLS-SEM analysis in R.

The learning logic is:

Read the paper
→ Understand the theory
→ Inspect the dataset
→ Check measurement quality
→ Estimate the structural model
→ Interpret results
→ Write research conclusions

Case Study Information

Item Description
Research area Technology Acceptance
Method PLS-SEM
Theory UTAUT2
Journal example Innovative Higher Education
Published sample size 503 students
Replication tool R using seminr
Dataset used here Synthetic teaching dataset
WarningImportant Note About the Dataset

The dataset used in this case study is a synthetic teaching dataset.

It is generated to resemble the structure of the published study, but it is not the original raw data from the article. Therefore, the results should be interpreted as a learning exercise, not as a direct reproduction of the published coefficients.

Learning Objectives

After completing this case study, learners will be able to:

  • Understand the UTAUT2 framework.
  • Translate a theoretical model into a PLS-SEM model.
  • Identify latent constructs and measurement indicators.
  • Evaluate reliability and validity.
  • Interpret path coefficients, bootstrapping, and R-squared.
  • Decide what to do when results meet or fail reference thresholds.
  • Write a short academic-style interpretation.

Research Background

Artificial Intelligence tools such as ChatGPT are rapidly transforming higher education.

This case study asks:

What factors influence students’ behavioral intention and use behavior toward ChatGPT in higher education?

TipWhy This Case Matters

This case is useful because it combines:

  • A real research theory: UTAUT2.
  • A real research design: survey-based SEM.
  • A real academic workflow: measurement model first, structural model second.
  • A practical R workflow: data import, diagnostics, reliability, SEM, bootstrapping, interpretation.

Conceptual Framework

NoteWhat the Model Means

The model assumes that students’ intention to use ChatGPT is influenced by expected performance gains, perceived ease of use, social pressure, available support, enjoyment, price value, habit, and personal innovativeness.

Behavioral intention then predicts actual use behavior.

TipWhy Are We Doing This?

PLS-SEM requires complete and valid data for indicators.

Missing values can distort reliability, validity, and path estimates.

Step 5. Build the PLS-SEM Model

TipWhy Are We Doing This?

PLS-SEM has two parts:

  1. Measurement model: defines how indicators measure latent constructs.
  2. Structural model: defines relationships among latent constructs.

A clear separation between these two parts helps prevent model specification errors.

library(seminr)

measurement_model <- seminr::constructs(
  seminr::composite("PE", seminr::multi_items("PE", 1:4)),
  seminr::composite("EE", seminr::multi_items("EE", 1:4)),
  seminr::composite("SI", seminr::multi_items("SI", 1:3)),
  seminr::composite("FC", seminr::multi_items("FC", 1:3)),
  seminr::composite("HM", seminr::multi_items("HM", 1:3)),
  seminr::composite("PV", seminr::multi_items("PV", 1:3)),
  seminr::composite("HT", seminr::multi_items("HT", 1:4)),
  seminr::composite("PI", seminr::multi_items("PI", 1:4)),
  seminr::composite("BI", seminr::multi_items("BI", 1:3)),
  seminr::composite("UB", seminr::single_item("UB1"))
)

structural_model <- seminr::relationships(
  seminr::paths(
    from = c("PE", "EE", "SI", "FC", "HM", "PV", "HT", "PI"),
    to = "BI"
  ),
  seminr::paths(
    from = c("FC", "HT", "BI"),
    to = "UB"
  )
)

pls_model <- seminr::estimate_pls(
  data = utaut_data,
  measurement_model = measurement_model,
  structural_model = structural_model
)

pls_summary <- summary(pls_model)

# Step 5. Build the PLS-SEM Model

::: {.callout-tip}
## Why Are We Doing This?

PLS-SEM has two parts:

1. **Measurement model**: defines how indicators measure latent constructs.
2. **Structural model**: defines relationships among latent constructs.

A clear separation between these two parts helps prevent model specification errors.
:::

```{r}

library(seminr)

measurement_model <- seminr::constructs(
  seminr::composite("PE", seminr::multi_items("PE", 1:4)),
  seminr::composite("EE", seminr::multi_items("EE", 1:4)),
  seminr::composite("SI", seminr::multi_items("SI", 1:3)),
  seminr::composite("FC", seminr::multi_items("FC", 1:3)),
  seminr::composite("HM", seminr::multi_items("HM", 1:3)),
  seminr::composite("PV", seminr::multi_items("PV", 1:3)),
  seminr::composite("HT", seminr::multi_items("HT", 1:4)),
  seminr::composite("PI", seminr::multi_items("PI", 1:4)),
  seminr::composite("BI", seminr::multi_items("BI", 1:3)),
  seminr::composite("UB", seminr::single_item("UB1"))
)

structural_model <- seminr::relationships(
  seminr::paths(
    from = c("PE", "EE", "SI", "FC", "HM", "PV", "HT", "PI"),
    to = "BI"
  ),
  seminr::paths(
    from = c("FC", "HT", "BI"),
    to = "UB"
  )
)
```

When writing SEM results, follow this sequence:

1. Measurement model
2. Discriminant validity
3. Structural model
4. R-squared
5. Hypothesis testing
6. Theoretical interpretation
:::

## Example Results Text

The measurement model showed acceptable indicator reliability, as most item loadings exceeded the recommended threshold of 0.70. Internal consistency was also acceptable, with reliability estimates above the commonly used threshold of 0.70. The HTMT values indicated adequate discriminant validity among constructs.

The structural model results suggested that several UTAUT2 predictors were positively associated with Behavioral Intention. Habit and Performance Expectancy were particularly important predictors. Behavioral Intention, Habit, and Facilitating Conditions contributed to Use Behavior. These findings support the usefulness of UTAUT2 for explaining students' acceptance and use of ChatGPT in higher education.

::: {.callout-warning}
## Writing Caution

Do not write:

> This proves that Habit causes ChatGPT use.

Instead, write:

> The results suggest a positive association between Habit and Use Behavior within the specified model.

Survey-based SEM supports theoretical relationships, but causal claims require stronger research designs.
:::
