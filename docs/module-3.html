3.1 Why Descriptive Statistics Matter?

NoteKnowledge Notes

What?

Thống kê mô tả là bước dùng để tóm tắt đặc điểm chính của bộ dữ liệu.

Why?

Trước khi chạy bất kỳ phân tích hay mô hình từ cơ bản đến nâng cao, nhà nghiên cứu cần hiểu:

  • Mẫu nghiên cứu gồm những ai?
  • Các biến có phân phối như thế nào?
  • Có giá trị bất thường không?
  • Các nhóm có khác nhau không?

When?

Luôn thực hiện sau data cleaning và trước modeling.

How do we use it in research?

Thống kê mô tả thường xuất hiện trong:

  • Đặc điểm mẫu quan sát (Sample characteristics)
  • Phân tích sơ bộ (Preliminary analysis)
  • Kết quả mô tả (Descriptive results)
  • So sánh nhóm (Group comparison)
ImportantResearch Application

Trong các bài nghiên cứu, Module 3 hỗ trợ viết các phần:

Sample Characteristics
Descriptive Statistics
Preliminary Analysis
Group Comparison

Đây là nền tảng cho các nghiên cứu tiếp theo.

WarningCommon Mistakes

Người học thường mắc lỗi:

  • Chạy phân tích chính trước khi mô tả dữ liệu
  • Chỉ báo cáo mean mà không báo cáo SD
  • Không kiểm tra phân phối
  • Không báo cáo effect size
  • Diễn giải p-value mà không nói ý nghĩa thực tiễn

3.4 Prepare Analysis Variables

NoteKnowledge Notes

What?

Một số phân tích cần biến trung bình như bi_mean, pe_mean, tr_mean.

Why?

Các biến trung bình giúp mô tả và hồi quy các cấu trúc nghiên cứu.

How?

Nếu các biến này chưa tồn tại, ta tạo lại từ các item Likert.

needed_mean_vars <- c(
  "pe_mean", "ee_mean", "si_mean", "fc_mean",
  "dr_mean", "tr_mean", "bi_mean", "au_mean"
)

if (!all(needed_mean_vars %in% names(data))) {
  data <- data |>
    mutate(
      pe_mean = rowMeans(pick(pe1, pe2, pe3, pe4), na.rm = TRUE),
      ee_mean = rowMeans(pick(ee1, ee2, ee3, ee4), na.rm = TRUE),
      si_mean = rowMeans(pick(si1, si2, si3, si4), na.rm = TRUE),
      fc_mean = rowMeans(pick(fc1, fc2, fc3, fc4), na.rm = TRUE),
      dr_mean = rowMeans(pick(dr1, dr2, dr3, dr4), na.rm = TRUE),
      tr_mean = rowMeans(pick(tr1, tr2, tr3, tr4), na.rm = TRUE),
      bi_mean = rowMeans(pick(bi1, bi2, bi3), na.rm = TRUE),
      au_mean = rowMeans(pick(au1, au2, au3), na.rm = TRUE)
    )
}

Convert Categorical Variables

data <- data |>
  mutate(
    gender = as.factor(gender),
    major = as.factor(major),
    campus = as.factor(campus)
  )

WarningCommon Mistakes

Không nên chỉ báo cáo mean.

Với biến định lượng, tối thiểu nên báo cáo:

Mean ± SD

hoặc:

Median [IQR]

nếu phân phối lệch mạnh.

3.14 Academic Reporting

NoteKnowledge Notes

What?

Academic reporting là cách viết kết quả thống kê thành văn bản học thuật.

Why?

Người đọc cần hiểu ý nghĩa kết quả, không chỉ nhìn output R.

Template for Descriptive Statistics

ENG:
The sample consisted of [N] respondents. The average Behavioral Intention score was [M] (SD = [SD]). Table 1 presents the demographic and descriptive characteristics of the sample.
VI:
Mẫu nghiên cứu bao gồm [N] người trả lời. Điểm trung bình về Ý định Hành vi là [M] (SD = [SD]). Bảng 1 trình bày các đặc điểm nhân khẩu học và mô tả của mẫu nghiên cứu.

Template for t-test

An independent-samples t-test was conducted to compare Behavioral Intention between gender groups. The results showed that the difference was [statistically significant / not statistically significant], t(df) = ..., p = .... This suggests that gender [was / was not] associated with differences in Behavioral Intention.

Template for ANOVA

A one-way ANOVA was conducted to examine whether Behavioral Intention differed across majors. The results indicated that the difference among majors was [statistically significant / not statistically significant], F(df1, df2) = ..., p = .... Post hoc comparisons were conducted to identify specific group differences.

# 3.1 Why Descriptive Statistics Matter?

::: {.callout-note title="Knowledge Notes"}
**What?**

Thống kê mô tả là bước dùng để tóm tắt đặc điểm chính của bộ dữ liệu.

**Why?**

Trước khi chạy bất kỳ phân tích hay mô hình từ cơ bản đến nâng cao, nhà nghiên cứu cần hiểu:

- Mẫu nghiên cứu gồm những ai?
- Các biến có phân phối như thế nào?
- Có giá trị bất thường không?
- Các nhóm có khác nhau không?

**When?**

Luôn thực hiện sau data cleaning và trước modeling.

**How do we use it in research?**

Thống kê mô tả thường xuất hiện trong:

- Đặc điểm mẫu quan sát (Sample characteristics)
- Phân tích sơ bộ (Preliminary analysis)
- Kết quả mô tả (Descriptive results)
- So sánh nhóm (Group comparison)
:::

::: {.callout-important title="Research Application"}
Trong các bài nghiên cứu, Module 3 hỗ trợ viết các phần:

``` text
Sample Characteristics
Descriptive Statistics
Preliminary Analysis
Group Comparison
```

Đây là nền tảng cho các nghiên cứu tiếp theo.
:::

::: {.callout-warning title="Common Mistakes"}
Người học thường mắc lỗi:

- Chạy phân tích chính trước khi mô tả dữ liệu
- Chỉ báo cáo mean mà không báo cáo SD
- Không kiểm tra phân phối
- Không báo cáo effect size
- Diễn giải p-value mà không nói ý nghĩa thực tiễn
:::

```{r}
needed_mean_vars <- c(
  "pe_mean", "ee_mean", "si_mean", "fc_mean",
  "dr_mean", "tr_mean", "bi_mean", "au_mean"
)

if (!all(needed_mean_vars %in% names(data))) {
  data <- data |>
    mutate(
      pe_mean = rowMeans(pick(pe1, pe2, pe3, pe4), na.rm = TRUE),
      ee_mean = rowMeans(pick(ee1, ee2, ee3, ee4), na.rm = TRUE),
      si_mean = rowMeans(pick(si1, si2, si3, si4), na.rm = TRUE),
      fc_mean = rowMeans(pick(fc1, fc2, fc3, fc4), na.rm = TRUE),
      dr_mean = rowMeans(pick(dr1, dr2, dr3, dr4), na.rm = TRUE),
      tr_mean = rowMeans(pick(tr1, tr2, tr3, tr4), na.rm = TRUE),
      bi_mean = rowMeans(pick(bi1, bi2, bi3), na.rm = TRUE),
      au_mean = rowMeans(pick(au1, au2, au3), na.rm = TRUE)
    )
}
```

# 3.14 Academic Reporting

::: {.callout-note title="Knowledge Notes"}
**What?**

Academic reporting là cách viết kết quả thống kê thành văn bản học thuật.

**Why?**

Người đọc cần hiểu ý nghĩa kết quả, không chỉ nhìn output R.
:::

## Template for Descriptive Statistics

``` text
ENG:
The sample consisted of [N] respondents. The average Behavioral Intention score was [M] (SD = [SD]). Table 1 presents the demographic and descriptive characteristics of the sample.
VI:
Mẫu nghiên cứu bao gồm [N] người trả lời. Điểm trung bình về Ý định Hành vi là [M] (SD = [SD]). Bảng 1 trình bày các đặc điểm nhân khẩu học và mô tả của mẫu nghiên cứu.
```

## Template for t-test

``` text
An independent-samples t-test was conducted to compare Behavioral Intention between gender groups. The results showed that the difference was [statistically significant / not statistically significant], t(df) = ..., p = .... This suggests that gender [was / was not] associated with differences in Behavioral Intention.
```

## Template for ANOVA

``` text
A one-way ANOVA was conducted to examine whether Behavioral Intention differed across majors. The results indicated that the difference among majors was [statistically significant / not statistically significant], F(df1, df2) = ..., p = .... Post hoc comparisons were conducted to identify specific group differences.
```
